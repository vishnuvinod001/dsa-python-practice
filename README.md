# 🧠 DSA Practice in Python

A curated collection of Data Structures and Algorithms problems implemented in Python for interview preparation and continuous problem-solving practice.

---

## 📂 Topics Covered

- Arrays & Strings
- Hash Maps (Frequency Counting, Lookup Optimization)
- Two Pointers
- Binary Search & Binary Search on Answer
- Stack (Monotonic Stack, Expression Processing)
- Linked Lists (Traversal, Reversal, Fast & Slow Pointers)
- Trees & Binary Trees (DFS, BFS, Recursive Traversal)
- Trie (Prefix Tree)
- Recursion
- Dynamic Programming
  - Memoization (Top-Down DP)
  - Tabulation (Bottom-Up DP)
  - 1D Dynamic Programming
  - Coin Change Pattern
- Greedy Algorithms
- Sliding Window
- Prefix Sum
- Sorting & Searching Algorithms
---

- Strengthen algorithmic thinking
- Practice coding patterns
- Prepare for technical interviews
